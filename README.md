# 🤖 ENCS5343: Deep Learning for Arabic Handwritten Text Identification

## 📌 Overview
This repository contains my implementation of the **Course Project: Arabic Handwritten Text Identification Using Deep Learning** for the **ENCS5343: Computer Vision** course at **Birzeit University**. The project builds upon previous assignments by utilizing **Convolutional Neural Networks (CNNs)** to solve the handwritten text recognition problem.

## 🛠 Features
- ✅ **Custom CNN Model:** Designed and trained from scratch with optimized hyperparameters.
- ✅ **Data Augmentation:** Techniques applied to improve generalization and performance.
- ✅ **Pretrained CNN Models:** Transfer learning with well-known architectures (e.g., VGG16, ResNet).
- ✅ **Comparative Analysis:** Performance evaluation of different models using accuracy, loss curves, and visualization.
- ✅ **Transfer Learning:** Fine-tuning pretrained networks for better results.

## 📂 Contents
- 📜 **Python Code:** Implementation of all tasks including model training and evaluation.
- 🗄 **Dataset:** Arabic Handwritten Automatic Word Processing (AHAWP) dataset.
- 📊 **Results & Analysis:** Accuracy, loss curves, and comparative studies.
- 📄 **Report:** Methodology, experimental setup, results, and discussion.
